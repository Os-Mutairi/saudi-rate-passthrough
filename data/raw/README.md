# Raw data (not included)

Download these into this folder before running the scripts (see the main
README for details). Keep the FRED file names exactly as shown.

| File | Where to get it |
|---|---|
| `DFEDTARU.csv` | https://fred.stlouisfed.org/series/DFEDTARU (Download -> CSV) |
| `DFEDTARL.csv` | https://fred.stlouisfed.org/series/DFEDTARL (Download -> CSV) |
| `POILBREUSDM.csv` | https://fred.stlouisfed.org/series/POILBREUSDM (Download -> CSV) |
| `POILDUBUSDM.csv` | https://fred.stlouisfed.org/series/POILDUBUSDM (Download -> CSV) |
| `SAMA_*.xls` (interest rates) | SAMA Statistical Report, Exchange Rates and Interest Rates -> *Monetary Indicators: (Interest Rates)*, all series. All available dates, Monthly, **Export (Excel)** |
| `SAMA_*.xls` (private credit) | SAMA Monetary and Financial Statistics -> Credit from Banks -> *Bank Claims On Private Sector*: all lines. All available dates, Monthly, **Export (Excel)** |
| `SAMA_*.xls` (real estate loans, optional) | Same section -> *Real Estate Loans By Banks* (Retail, Corporate, Total). Quarterly, **Export (Excel)** |

SAMA file names can be anything starting with `SAMA`; the scripts identify
each file by its content. Use Excel export, not PDF (PDF only has recent years).
Data used in V1 were downloaded on 19 October 2026.
